# Scheduler Backend Server

Простой бэкенд для поддержки многопользовательского режима планировщика.

## Установка

```bash
cd server
npm install
```

## Запуск

```bash
npm start
```

Сервер запустится на `http://localhost:3000`

Для разработки с автоматической перезагрузкой:

```bash
npm run dev
```

## Использование

### Общий календарь
Откройте `http://localhost:3000` - данные хранятся на сервере (группа `default`) и одинаковы на всех устройствах.
Дела, ранее сохранённые в localStorage браузера, при первом открытии один раз переносятся на сервер.

Если страница открыта без сервера (например, на GitHub Pages), данные хранятся в localStorage браузера.

### Групповой режим
Откройте `http://localhost:3000/group/[ID]` где `[ID]` - любой идентификатор группы (например, `1234`, `my-team`, и т.д.)

**Примеры:**
- `http://localhost:3000/group/1234`
- `http://localhost:3000/group/family`
- `http://localhost:3000/group/work-team`

Все пользователи, открывшие один и тот же URL группы, будут видеть общий календарь с задачами. Изменения синхронизируются в реальном времени через WebSocket.

### Важно
- **Задачи (tasks)** и **заметки месяцев** - общие для всех участников группы, хранятся на сервере
- **Настройки (settings)** - индивидуальные для каждого пользователя, хранятся в localStorage

## Хранение данных

Данные каждой группы сохраняются в JSON-файл `server/data/<groupId>.json` (каталог можно поменять переменной окружения `DATA_DIR`).
Запись идёт с небольшой задержкой (300 мс) и атомарно (через временный файл), при остановке сервера (SIGINT/SIGTERM) несохранённые изменения сбрасываются на диск.

## API Endpoints

### GET `/api/groups/:groupId`
Получить все данные группы: `{ "tasks": [...], "monthNotes": {...} }`

### GET `/api/groups/:groupId/tasks`
Получить все задачи для группы

### POST `/api/groups/:groupId/tasks`
Обновить задачи для группы

Body: `{ "tasks": [...] }`

## WebSocket Events

### Client -> Server
- `join-group` - присоединиться к группе
- `update-tasks` - обновить задачи группы
- `update-month-note` - обновить заметку месяца `{ groupId, key, value }`
- `leave-group` - покинуть группу

### Server -> Client
- `tasks-updated` - задачи группы обновлены
- `month-notes-updated` - заметки месяцев обновлены

## Технологии
- Express.js - веб-сервер
- Socket.io - WebSocket для real-time синхронизации
- CORS - для поддержки запросов с разных доменов

## Заметки
- Изменения задач отправляются целым списком: при одновременной правке разными участниками побеждает последняя запись
